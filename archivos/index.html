Archivos explicativos¶

Aquí se publican los documentos que explican el proyecto. Para añadir uno nuevo:

  1. Copia el archivo (PDF, imagen, ZIP...) dentro de la carpeta docs/archivos/.
  2. Añade una fila a la tabla de abajo con el enlace.
  3. Ejecuta properdocs serve para comprobarlo.
